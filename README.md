#This project is titled as KoodamKood, it is basically an extension of Mario game where we have 3 different dimensions.

While building this game, we built three different dimensions, the hell, the heaven and the earth, they were made completely by us without the use of any AI, then we gave AI the inspiration of those 3 files and asked it to integrate it, since we couldnt do it ourselves due to time limitations. I would love if you take a moment and import those files in godot and try to run it, you wont be disappointed especially from Heaven and Earth.
- Heaven is new-game-project
- Earth is game.zip
- hell is hell

To run the game:-
1) Find and import the KoodamKood.zip inside Godot game engine
