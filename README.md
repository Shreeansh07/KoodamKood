# KoodamKood

2D platformer in **Godot 4.3** (GL Compatibility renderer). Three stacked dimensions: **Heaven**, **Earth**, **Hell**.

## Run
1. Extract the ZIP, open Godot 4.3+ -> Import -> select `project.godot`.
2. Wait for the first asset import to finish (the `.godot` cache is not shipped), then press **F5**. Main scene: `res://scenes/Menu.tscn`.
3. If you export the game, add `*.json` to the export "Resources to export" filter (levels are JSON).

## Controls
A/D or Left/Right move - Space/W/Up/Z jump (hold = higher) - Esc/P pause (volume sliders) - R retry on game over.
Menu: Left/Right choose hero (Knight, Ace, Zoe, Max, Mia, Bolt), Enter play.

## Rules
- Start on Earth. Reach the castle flag in Heaven to win.
- Fall out of Heaven -> Earth; fall out of Earth -> Hell; fall out of Hell -> death.
- Lifts (gold chevrons) in Earth and Hell carry you up one dimension if you are still aboard at the top.
- Jump ON mobs to squash them; touching from the side/below kills you. Spikes kill.
- Hell: 75 s timer. At 0 a zombie (Kenney Toon zombie) spawns, locks the lifts and hunts you at 235 px/s (player max 125). It cannot be escaped.

## Audio mapping
Brackeys has ONE music track, so all three dimensions play it: Heaven pitched up (1.08), Earth normal, Hell slowed (0.72) with a low-pass filter. SFX: jump, coin = Brackeys; stomp = explosion; death = hurt; lift/dimension change = power_up; menu click = tap.
Not in Brackeys, so synthesized by `tools/gen_audio.py`: warning beeps, zombie roar, fall whoosh, win jingle, and the "oo loser" line (**synthetic text-to-speech via ffmpeg flite, not a recorded voice** - replace `assets/audio/loser.wav` with a real clip if you have one).

## What is NOT as requested (be aware)
- Brackeys contains **no background art and no flying enemies**: Earth's background is Kenney Pixel Platformer tiles (the same pale hill look as your screenshots), and Earth's "flyers" are bouncing Brackeys slimes instead.
- Hell coins are Kenney diamonds (Brackeys coin is used in Heaven and Earth).
- **This project was NOT opened or run in Godot** (no Godot binary available while building; your screenshots show Godot 4.7.2, which should open this 4.3-format project and may offer to upgrade it). Layouts, tile choices and asset paths were verified with Python only (`tools/preview_levels.py`, fairness checks, resource-path scan); the GDScript is untested. Expect to fix small errors on first run.
- The Sploob-inspired menu is an original three-band layout; I could not view the itch.io page.
